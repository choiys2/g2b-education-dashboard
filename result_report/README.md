# 교육청 연수 결과보고 자동화

RMS 원본(3.결과보고 자료) 1개 + 입력값 엑셀 1개를 넣으면 교육청 제출 서류 일체를 만든다.
업무 인계서(교육청연수전략Cell, 2022) 2-8~2-14쪽 절차를 그대로 코드로 옮겼다.

## 준비물

| 파일 | 어디서 | 비고 |
| --- | --- | --- |
| 원본 | RMS 관리자 → 성적산출관리 → 이수결과관리 → 기수찾기 → **3.결과보고 자료 다운** | 받은 그대로 |
| 입력값.xlsx | `--init`으로 생성 후 작성 | 사업명·수신처·계약예산(영업 최종 견적가)·학점별 단가·청구일·만족도 응답수·후기 |
| 이수자분석양식.xlsx | 기존 양식 | 피벗·그래프 포함 원본 그대로 사용 |
| 청구서양식.xls | 기존 양식 | 직인·서식 유지 |

> 원본·양식·산출물에는 개인정보(성명·생년월일·나이스번호·휴대폰)가 있으므로 **저장소에 올리지 않는다.**
> `result_report/work/` 아래에 두면 `.gitignore`로 제외된다.

## 실행

```bash
pip install openpyxl lxml python-hwpx     # 청구서는 LibreOffice(soffice)도 필요
python result_report/build_result_report.py --init result_report/work/입력값.xlsx
python result_report/build_result_report.py \
  --raw result_report/work/GG2504-15.xlsx \
  --input result_report/work/입력값.xlsx \
  --analysis-template result_report/work/이수자분석양식.xlsx \
  --invoice-template result_report/work/청구서양식.xls \
  --out result_report/work/out
```

## 원본 정리 규칙 (`rr_clean.py`)

GG2504-15 실제 결과보고본과 원본을 대조해 역산한 규칙이다. 결과가 실제 보고본과 셀 단위로 같다.

- 관할교육청: 입력값의 '관할교육청(정리 통일값)'으로 통일
- 직위: 공란→교사, 기간제·수석·사서·영양교사·정보부장 등→교사, 교육연구사·교육전문직→교육공무직
  (분석양식 직위표 7칸 합계를 맞추기 위한 인계서 규칙)
- 학교구분: 공란→소속이 교육청이면 기타, 학교면 공립
- 정렬: 이수자 먼저(원본 순서 유지), 미이수자 뒤
- 점검: **이수자 나이스번호 누락 → 문자요청 대상**(보고 후에도 받아서 추가 제출), 나이스번호 형식 이상,
  이수자 이수번호 누락·중복, 생년월일·휴대폰 형식

## 청구 금액 계산 (`rr_stats.invoice`)

```
과정 금액 = 이수 인원 × 단가(1학점 / 2학점)
산정 금액 = Σ 과정 금액
교육기부 = min(0, 계약예산 − 산정 금액)      # 예산을 넘는 이수분은 무상 처리
청구 금액 = 산정 금액 + 교육기부
```

청구서 합계 셀을 LibreOffice로 재계산해 위 값과 다르면 중단한다(비용 오류 방지).

## 만족도

강의평가 통계의 문항별 응답 수를 입력값 '만족도' 시트에 넣는다. 추천 지수는 보기 3개 설문이라
1·2·3번 응답 수를 '매우 그렇다·그렇다·보통' 칸에 넣는다(인계서 규칙). 평균 = (5×매우그렇다 + … + 1×매우아니다) ÷ 조사인원.

## 양식이 바뀌면

- 청구서 셀 위치: `rr_invoice.py`의 `CELLS`, `FIRST_LINE_ROW`, `TEMPLATE_LINES`
- 분석양식 시트명: `rr_xlsx_template.py`의 `DATA_SHEET`, `SURVEY_SHEET`
- 한글 보고서 문구·목차: `rr_hwpx.py`의 `build()`

## 웹 버전 (`web/`)

같은 규칙을 브라우저 안에서 돌리는 단일 페이지. 원본·개인정보는 서버로 가지 않고 브라우저에서만 처리된다.

- `web/app.html` — 화면과 로직(정리·집계·청구·HWPX/xlsx 양식 채우기). 양식은 빌드 때 삽입
- `web/build_web.py` — 담당자 PC의 원본 양식(결과보고서 hwpx, 청구서 xls, 이수자분석양식 xlsx)을
  변환·비식별화해 `app.html`에 넣고 배포용 HTML 하나를 만든다

```bash
python result_report/web/build_web.py --report-hwpx 결과보고서양식.hwpx \
  --invoice-xls 청구서양식.xls --analysis-xlsx 이수자분석양식.xlsx --out dist/결과보고_자동화.html
```

한글 결과보고서는 양식의 표·문장·차트 값만 바꾸고(고친 문단의 줄배치 캐시만 삭제) 나머지 서식은 그대로 둔다.
과정 수·기수 수·직급 수에 맞춰 표 줄을 늘리거나 줄인다.
