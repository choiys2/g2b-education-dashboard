3결과보고 공문

공문은 붙여넣지 않아도 자동으로 만들어집니다 — 사업명·수신·기간·대상·담당은 2단계 입력값, 결과 표는 원본에서 계산합니다. 그룹웨어에서만 나오는 문서번호·발행일자·결재라인은 아래에 공문을 붙여넣거나 직접 적으세요.
