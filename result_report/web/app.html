1원본 올리기

RMS 관리자 → 성적산출관리 → 이수결과관리 → 기수찾기 → 3.결과보고 자료 다운 파일(또는 교육청 수강자명단)을 그대로 올리세요.

과정별 이수 현황 · 과정 정보(대상·시간)

대상·시간은 결과보고서 '연수 구성' 표에 들어갑니다. 고치면 팀 전체가 다음에도 같은 값을 씁니다.

5검증 · 서류 받기

검증은 실제로 서류를 만들어 다시 읽어 보고, 숫자가 서로 맞는지(청구서·결과보고서·공문·명단), 빠진 입력이나 남은 예전 문구가 없는지 확인합니다.
