# 🌷 코지 가든 (Cozy Garden)

동물의 숲 스타일의 아기자기한 정원 가꾸기 웹 게임. 외부 라이브러리 없이
순수 HTML5 Canvas + JavaScript로 작성된 단일 파일 게임입니다.

이 저장소(`g2b-education-dashboard`)의 나라장터 대시보드 코드와는 독립적인
프로젝트로, 기존 파이프라인/빌드 스크립트에 영향을 주지 않습니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 실행됩니다. 별도 빌드나 서버가 필요 없습니다.

```bash
open cozy-garden/index.html   # macOS
# 또는 그냥 파일 탐색기에서 더블클릭
```

## 게임 방법

- **⛏️ 갈기**: 잔디를 갈아 씨앗을 심을 수 있는 흙으로 만듭니다.
- **🌱 심기**: 해바라기/튤립/장미 중 씨앗을 골라 흙 위에 심습니다.
- **💧 물주기**: 심은 식물에 물을 줘서 성장 속도를 높입니다.
- **🧺 수확**: 다 자란 꽃을 수확해 골드를 얻습니다.
- **🏡 꾸미기**: 상점에서 산 울타리/벤치/조명을 잔디 위에 배치·이동합니다.
- **🛒 상점**: 골드로 씨앗과 꾸미기 아이템을 구매합니다.
- **화살표 키**: 캐릭터를 정원 안에서 움직입니다.

낮과 밤이 천천히 순환하며, 밤에는 반딧불이와 조명이 은은하게 빛납니다.
