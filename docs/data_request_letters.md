## ① 한국교직원공제회 학교장터(S2B) 운영 담당 귀하

**제목:** 학교장터(S2B) 견적요청·계약 공개 정보의 정형 데이터 제공 요청

1. 귀 기관의 무궁한 발전을 기원합니다.
2. 당사는 「교원 등의 연수에 관한 규정」에 따라 지정된 원격교육연수원으로, 시도교육청과 학교의 교원 연수 수요에 맞는 과정을 개발·운영하고 있습니다.
3. 학교장터(s2b.kr)는 학교 단위 소액 용역(교원 연수·컨설팅 등) 수요를 파악할 수 있는 유일한 창구이나, 사이트 이용 정책(robots.txt)상 자동 수집이 제한되어 있어 이를 존중하여 자동 수집을 하지 않고 있습니다.
4. 이에 아래와 같이 공개 범위 내 정보의 정형 데이터 제공(공공데이터포털 등록 또는 정기 파일 제공)을 요청드립니다.

| 구분 | 내용 |
|---|---|
| 대상 정보 | 견적요청 공고 및 계약 체결 결과 중 **이미 학교장터에 공개된 항목** |
| 요청 항목 | 공고번호, 공고일·마감일, 기관명(학교명), 시도, 계약 구분(물품/용역/공사), 공고명(건명), 추정·계약 금액, 계약 방법 |
| 제외 항목 | 담당자 성명·연락처 등 개인정보, 비공개 정보 일체 |
| 범위 | 용역 분야(가능하면 '연수·교육·컨설팅' 관련 건) / 최근 12개월 + 이후 정기 갱신 |
| 형식·주기 | 공공데이터포털 파일데이터 또는 Open API / 월 1회 이상 |
| 활용 목적 | 학교 수요 맞춤 연수 과정 개발, 소규모 학교 공동 연수 상품 기획(영리 목적 2차 배포 없음) |

5. 정형 데이터 제공이 어려운 경우, 자동 조회를 허용하는 범위(경로·호출 빈도)를 안내해 주시면 그 범위를 지켜 이용하겠습니다.

붙임: 회사 소개 및 데이터 활용 계획 1부. 끝.

## ② ○○시도교육청 재정(계약) 담당 귀하

**제목:** 수의계약 공개 정보(K-에듀파인 연계)의 공공데이터 개방 요청

1. 귀 청의 교육 발전을 기원합니다.
2. 귀 청 홈페이지 '정보공개 > 재정공개 > 수의계약'에 K-에듀파인과 연계해 공개 중인 학교·기관 수의계약 정보(1백만원 이상)를 연수 수요 분석에 활용하고자 합니다.
3. 현재 해당 화면은 해외 서버 접속 제한 또는 자동 조회 제한으로 정기적 활용이 어렵습니다. 이에 **이미 공개 중인 항목**을 공공데이터포털(data.go.kr) 파일데이터 또는 Open API로 개방해 주실 것을 요청드립니다(「공공데이터의 제공 및 이용 활성화에 관한 법률」 제27조 공공데이터 제공 신청 준용).

| 구분 | 내용 |
|---|---|
| 요청 항목 | 회계연도, 계약기관(학교명), 기관 구분, 계약명, 계약 방법, 계약일자, 계약금액, 계약상대자(법인명) |
| 제외 항목 | 개인 계약상대자 성명 등 개인정보 |
| 형식·주기 | CSV(UTF-8) 월 1회 갱신, 또는 Open API |
| 활용 목적 | 교원 연수 수요 분석 및 맞춤형 과정 개발 |

4. 참고로 전라남도교육청은 '수의계약정보'를 공공데이터포털에 표본 파일로 공개하고 있습니다(데이터셋 15150722). 전체 기간 파일로 확대 공개해 주시면 감사하겠습니다.

붙임: 데이터 활용 계획 1부. 끝.
